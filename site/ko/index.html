화면을 몇 초 만에 GIF로

짤캠(zzalcam)은 윈도우에서 창, UI 컨트롤 하나, 드래그한 영역, 모니터 전체를 녹화해서 화질은 지키면서 최대한 작은 GIF나 WebP 움짤로 저장하는 화면 녹화 프로그램입니다.

윈도우용 다운로드 GitHub에서 소스 보기

무료 오픈소스(GPL-3.0-or-later) · Windows 10 2004 이상, x64

기능

  • 무엇이든 선택

    단축키 하나로 모든 모니터에 선택 화면이 뜹니다. 드래그하면 영역, 클릭하면 창, Tab은 컨트롤 하나, F는 모니터, A는 전체 모니터입니다. 돋보기로 픽셀 단위까지 맞출 수 있습니다.

  • 작은 용량

    GIF 프레임마다 바뀐 부분만 저장하고, 바뀌지 않은 픽셀은 투명으로 처리하며, 팔레트 하나를 공유합니다. 벤치마크에서 같은 화질(PSNR) 기준 gifski보다 최대 약 31% 작았습니다.

  • 빠른 저장

    16스레드 데스크톱 CPU에서 10초짜리 1080p 클립을 3초 안에 저장했고, 녹화 중 CPU 사용량은 약 1%였습니다. 화면이 바뀔 때만 프레임을 기록합니다.

  • GIF·WebP와 용량 목표

    "8MB 이하로" 같은 목표를 주면 품질, 프레임레이트, 크기 순서로 낮춰 맞추고 무엇을 바꿨는지 알려 줍니다.

  • 편집기

    트림, 프레임 삭제, 크롭, 실제 속도 미리보기, 실행 취소와 다시 실행, 실시간 예상 용량을 지원합니다.

  • 공유에 최적화

    저장한 파일이 클립보드에 복사돼 디스코드나 슬랙에 바로 붙여 넣을 수 있습니다. 테두리, 컨트롤 바, 알림은 녹화에 찍히지 않습니다.

스크린샷

이럴 때 쓰세요

  • 움짤·짤 만들기

    브라우저나 플레이어, 게임 창에 나오는 장면을 화면 녹화해서 바로 움짤로 만듭니다. 동영상 파일을 GIF로 변환하는 과정 없이 녹화가 끝나면 GIF나 WebP 짤이 저장됩니다.

  • 버그 제보·사용법 공유

    프로그램 창이나 버튼 하나만 골라 GIF로 캡처해서 이슈, 메신저, 문서에 붙여 넣습니다. 용량이 작아 업로드 제한에 잘 걸리지 않습니다.

  • 가벼운 무료 녹화 프로그램

    꿀캠, 반디캠, 오캠, ScreenToGif, LICEcap 등으로 GIF 움짤을 만들던 분께 맞는 무료 오픈소스 화면 녹화·캡처(캡쳐) 프로그램입니다. 짤캠에는 광고나 워터마크가 없고 기능 제한도 없습니다.

설치와 사용법

설치

Releases에서 설치 파일이나 포터블 zip을 받으세요.

  • Windows 10 2004 이상, x64.
  • 설치 파일은 Microsoft WebView2가 없으면 함께 설치합니다(Windows 11에는 기본 포함). 포터블 버전은 WebView2가 이미 설치돼 있어야 합니다.
  • 아직 코드 서명을 하지 않아서 처음 실행할 때 SmartScreen 경고가 뜰 수 있습니다(추가 정보 → 실행).
  • 명령줄 도구 zzalcam-cli로 스크립트에서 녹화하고 인코딩할 수 있습니다.
