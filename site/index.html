Record your screen as a GIF in seconds

zzalcam records a window, a single UI control, a region or a whole monitor on Windows and saves it as a GIF or animated WebP that is as small as it can be without looking worse.

Download for Windows Source on GitHub

Free and open source (GPL-3.0-or-later) · Windows 10 2004 or later, x64

Features

  • Pick anything

    One hotkey opens a picker over every monitor: drag a region, click a window, press Tab for a single control, F for a monitor, A for all of them. A magnifier helps with pixel-exact edges.

  • Small files

    Each GIF frame keeps only what changed, unchanged pixels turn transparent and one palette is shared. In our benchmark, up to about 31 % smaller than gifski at the same PSNR.

  • Fast

    On a 16-thread desktop CPU, a 10-second 1080p clip was saved in under three seconds and recording used about 1 % CPU. Frames are stored only when the screen changes.

  • GIF or WebP, with a size limit

    Ask for "under 8 MB" and zzalcam lowers quality, then frame rate, then size until it fits, and tells you what it changed.

  • Editor

    Trim, delete frames, crop, preview at real speed, undo and redo, with a live size estimate.

  • Made for sharing

    The saved file goes to the clipboard, ready to paste into Discord or Slack. The border, control bar and notifications never appear in the recording.

Screenshots

Good for

  • Making GIFs and memes

    Record a scene from a browser, player or game window straight into a GIF or WebP, with no screen recording to convert afterwards.

  • Bug reports and how-tos

    Capture just one window or button as a GIF and paste it into an issue, a chat or a document. Files stay small enough for upload limits.

  • A light, free recorder

    Made GIFs with ScreenToGif, LICEcap or Honeycam before? zzalcam is a free, open-source screen recorder for the same job, with no ads, no watermark and no paid tier.

Install and use

Install

Download the installer or the portable zip from Releases.

  • Windows 10 version 2004 or later, x64.
  • The installer sets up Microsoft WebView2 if it is missing (it ships with Windows 11). The portable build expects WebView2 to be installed already.
  • Releases are not code-signed yet, so SmartScreen may warn on first launch (More info → Run anyway).
  • A command-line tool, zzalcam-cli, records and encodes from scripts.
